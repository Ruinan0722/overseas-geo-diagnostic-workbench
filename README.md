# 海外 GEO 诊断工作台 Demo

基于产品 PRD，并严格参考 TOPSFLO 与 Magcubic 两份客户版最佳实践报告制作的无后端、可真实交互 MVP。工作台目录与最终客户报告保持一致，演示数据保存在浏览器本地。

本产品与 CRM 无关。新建项目后，用户先按报告结构手工填写第一章「项目需求回顾」和第二章「品牌现状分析」，再进入网站诊断、优化方案与综合建议。

## 启动

```powershell
npm start
```

然后访问 <http://127.0.0.1:4173>。

## 推荐演示路径

1. 点击「开始 7 步引导」，跟随页面提示体验完整操作。
2. 点击「新建诊断项目」，仅填写项目名称、品牌、负责人和交付日期。
3. 手工填写并保存第一章「项目需求回顾」。
4. 手工填写并保存第二章「品牌现状分析」。
5. 查看第三章美国、德国、日本网站 GEO 基础诊断。
6. 在第四章切换意图问句、诊断结果、竞品 TOP10 和引用信源 TOP10。
7. 在第五章审核综合结论、优化意图目标和执行方式。
8. 点击「审核完整客户报告」，检查五章全部内容后导出 PDF。

## 最终报告目录

1. 项目需求回顾
2. 品牌现状分析
3. 网站 GEO 基础诊断
4. GEO 项目优化方案（最终意图、诊断结果、整体推荐 TOP10、引用信源 TOP10）
5. 综合诊断与 GEO 优化建议（整体结论、竞品分析、目标意图、优化方式）
